# Open data Métropole Rouen Normandie × SOLIDATA — dossier de cadrage (6 septembre 2026)

Chantier de **phase 1 (cadrage, aucun code modifié)** : recensement des données ouvertes du portail https://data.metropole-rouen-normandie.fr, propositions d'agrégation sur l'outil actuel, conception de la « fiche commune » pour les élus, architecture du connecteur, plan de phase 2 soumis à validation.

**Commencer par `00-rapport-developpement.md`** (synthèse en une page au §0, arbitrages demandés au §6.3).

| Fichier | Rôle |
|---|---|
| `00-rapport-developpement.md` | Rapport coordonné : état des lieux, 42 propositions priorisées en 6 lots, fiche commune, architecture, plan de phase 2, arbitrages, risques |
| `01-inventaire-catalogue.md` | Inventaire du portail (70 jeux vérifiés, 3 signalés, 8 besoins sans jeu), sources complémentaires, requêtes API à rejouer |
| `02-dechets-collecte.md` | Mémo thématique déchets & collecte textile (P-DEC) |
| `03-environnement-impacts.md` | Mémo thématique environnement & impacts (P-ENV) |
| `04-emploi-insertion-ess.md` | Mémo thématique emploi, insertion & ESS (P-EMP), analyse RGPD |
| `05-territoire-fiche-commune.md` | Mémo territoire, population, tableau de bord des élus (P-TER) — maquette de la fiche commune |
| `06-mobilite-tournees-remplissage.md` | Mémo mobilité, tournées, remplissage des bornes (P-MOB) |
| `07-cartographie-solidata.md` | Cartographie du code SOLIDATA à enrichir (`fichier:ligne`) |

Limite à connaître : le portail et les miroirs publics étaient bloqués par la politique réseau de la session de cadrage. L'inventaire vient de l'indexation web ; aucun schéma de champs n'a été lu. La phase 2 s'ouvre par un lot de vérification dont les commandes exactes sont écrites (`01` §4.2 et §6 de chaque mémo).
